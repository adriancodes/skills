# Synthetic fixture-service setup

Fixture docs, revision 2026-10-01. Dashboard URL: https://fixture-service.example.test/settings.

Choose Settings > Test environment > Credentials > Create test key. Select read-only fixture access. Copy the resulting test key. Live-environment keys are a different credential and cannot be used for this setup. The dashboard step is human-only. Local setup requires SERVICE_TEST_KEY. No CI secret is required.
