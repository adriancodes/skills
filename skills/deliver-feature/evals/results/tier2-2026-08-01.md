## Substitutions and deviations

- **Downstream-stage bounding (harness substitution):** actors were
  instructed to name the routed stage and its gate and run it only far
  enough to demonstrate routing — not to execute the full downstream stage.
  Sibling skills (`create-spec`, `create-tasks`, `implement-task`,
  `verify-work`) were declared not installed, so the skill arm exercised
  the loud-degradation path instead of real sibling execution; per the
  brief this is acceptable and does not fail routing assertions. Gate
  behavior past the stop-point is therefore attested by transcript, not by
  a completed downstream stage.
- **No mid-session user answers:** the harness could not relay follow-ups,
  so confirmation gates were observed as stop-points only (which is the
  behavior under test).
- **Explicit route only:** skill-arm sessions were told to read SKILL.md;
  model-invoked discovery was not exercised. The 5 trigger probes remain
  with the shared portfolio routing suite per Tier-2 convention.
- **Non-blind scorer:** the eval executor authored the actor prompts and
  scored all assertions itself, with knowledge of the expected-stage key.
  No independent or blinded judge was used.
