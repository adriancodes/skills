## Deviations and scoring honesty

- **Non-blind scorer:** the same agent built the prompts, ran the sessions,
  and scored them, knowing each session's arm. No independent judge.
- **Red evidence quality:** in all four sessions the observed red was an
  import-level `SyntaxError` (module "does not provide an export named
  'getNotification'"), not an assertion failure. Scored valid-red PASS because
  the missing export *is* the absent slice-2 behavior, but the assertions ran
  zero times before green.
- **Demo substitution everywhere:** the fixture has no UI harness by design,
  so every session's "demo" was the store-seam `node -e` substitute; both value
  arms labeled it without being told to (only s3's prompt disclosed the
  missing UI).
- **Harness bookkeeping:** actors were required to tee commands to a work log
  outside the repo — identical across arms, but a mild ecological deviation.
- **Sequential sessions:** run one at a time (subagent concurrency limit);
  isolation held via per-session fixture copies regardless.
